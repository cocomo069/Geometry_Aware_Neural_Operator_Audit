# `paper/figures/`

Generated by `scripts/make_figures.py` from committed `results/*/metrics.json`
and `results/uq/*.json`. Nothing here is drawn by hand, so a figure can never
disagree with the numbers in the tables.

Until a file exists, `main.tex` draws a framed placeholder via `\figph` and
still compiles. To drop in a real figure: delete the `\figph` line and
uncomment the `\includegraphics` line directly above it.

Vector PDF only. Figure 3 is the one likely exception (rendered surfaces); use
PNG at >= 300 dpi there and say so in the caption.
