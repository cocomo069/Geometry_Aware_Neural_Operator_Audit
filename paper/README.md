# paper/ — the manuscript

Two builds share one body:

| File | What it is |
|---|---|
| `body.tex` | All content (abstract through appendices); wide floats use `widefigure`/`widetable` environments the wrappers define |
| `main.tex` | Single-column wrapper (11pt article) — **this is the arXiv version** |
| `main_twocol.tex` | Two-column wrapper (10pt) |
| `macros.tex` | All notation macros (single definition per symbol) |
| `refs.bib` | Bibliography |
| `figures/` | Generated by `scripts/make_figures.py` + `scripts/render_examples.py`; PDF used by the paper, PNG mirror for browsing |
| `tables/` | Generated by `scripts/make_tables.py` as float bodies (caption + tabular, no `table` env) so one file serves both layouts |
| `main.pdf`, `main_twocol.pdf` | Committed builds |
| `arxiv_main.zip`, `arxiv_main_twocol.zip` | Self-contained arXiv source packages, built by `scripts/make_arxiv.py` |
| `ARXIV_SUBMISSION.md` | Submission runbook: what to upload, metadata, locked-in decisions |

Build:

```bash
cd paper && latexmk -pdf main.tex && latexmk -pdf main_twocol.tex
```

Regenerate everything the paper consumes, then repackage:

```bash
.venv/Scripts/python.exe -m scripts.make_tables
.venv/Scripts/python.exe -m scripts.make_figures
.venv/Scripts/python.exe -m scripts.render_examples
.venv/Scripts/python.exe -m scripts.make_arxiv --variant main
```

Do not hand-edit anything under `figures/` or `tables/`; fix the generating
script and regenerate. LaTeX aux files are gitignored.
