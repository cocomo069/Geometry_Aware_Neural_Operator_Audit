# paper/ — the manuscript

REVTeX 4.2, single source, two thin wrappers (the house layout from the
latex-paper-build skill):

| File | What it is |
|---|---|
| `body.tex` | The ENTIRE paper (title through bibliography); no `\documentclass`, no variant-conditional text |
| `preamble_shared.tex` | Packages, figure-width macros, wide-float environments, `\tblfont` hook, hyperref last |
| `single_column.tex` | Wrapper: `reprint,onecolumn` (NOT `preprint`, which strands the title page) |
| `two_column.tex` | Wrapper: `reprint` (the APS two-column journal look) |
| `macros.tex` | All notation macros (single definition per symbol) |
| `refs.bib` | Bibliography (REVTeX owns citations; never load natbib) |
| `figures/` | Generated by `scripts/make_figures.py` + `scripts/render_examples.py`, each drawn at its final printed width (7.05 in full / 3.4 in column) and inserted at 100% |
| `tables/` | Generated by `scripts/make_tables.py` as float bodies (caption + `\tblfont` + tabular, no `table` env) so one file serves both layouts |
| `pdf/` | The deliverables: `paper_single_column.pdf`, `paper_two_column.pdf` |
| `arxiv_single_column.zip`, `arxiv_two_column.zip` | Self-contained arXiv source packages, built by `scripts/make_arxiv.py` (single-column is the one to submit) |
| `ARXIV_SUBMISSION.md` | Submission runbook: what to upload, metadata, locked-in decisions |

Build:

```bash
cd paper && latexmk -pdf single_column.tex && latexmk -pdf two_column.tex
cp single_column.pdf pdf/paper_single_column.pdf
cp two_column.pdf pdf/paper_two_column.pdf
```

Regenerate everything the paper consumes, then repackage:

```bash
.venv/Scripts/python.exe -m scripts.make_tables
.venv/Scripts/python.exe -m scripts.make_figures
.venv/Scripts/python.exe -m scripts.render_examples
.venv/Scripts/python.exe -m scripts.make_arxiv --variant single_column
```

Do not hand-edit anything under `figures/` or `tables/`; fix the generating
script and regenerate. LaTeX aux files and the raw latexmk PDFs are
gitignored; only `pdf/` copies are committed.
